title=PZ Control - RCON + Web Admin Panel
description=[h1]Project Zomboid Control - RCON + Web Admin Panel[/h1]
description=
description=A self-hosted admin panel and RCON controller for [b]Project Zomboid dedicated servers on Linux[/b]. This is an external tool, not an in-game mod. Nothing needs to be installed in your game or on your players' computers.
description=
description=[h2]Features[/h2]
description=[list]
description=[*] Live player list, kick/ban and any RCON command
description=[*] Host and Java metrics (CPU, memory, uptime)
description=[*] Edit server .ini, SandboxVars and spawn files, with automatic backups
description=[*] Start / stop / restart the game service, with a "SERVER STARTED" indicator
description=[*] Live rolling server log
description=[*] Multiple users, each with their own password
description=[*] Two-factor authentication (TOTP) with any authenticator app (Google Authenticator, Authy, Microsoft Authenticator, 1Password...)
description=[*] HTTPS via Caddy, and a certificate download for new computers
description=[*] Optional Windows desktop client that remembers your servers
description=[/list]
description=
description=[h2]Install[/h2]
description=[olist]
description=[*] Enable RCON in your server's .ini (RCONPort and RCONPassword).
description=[*] Download the [b]server installer[/b] from the releases page and run it on your Linux server.
description=[*] Open the panel address in a browser, or install the [b]Windows client[/b].
description=[*] Turn on two-factor authentication in the Security tab.
description=[/olist]
description=
description=[b]Downloads, full instructions and source code:[/b]
description=[url=https://github.com/Jojaslav/project-zomboid-servercontrol/releases]https://github.com/Jojaslav/project-zomboid-servercontrol/releases[/url]
description=
description=[h2]Security[/h2]
description=Your RCON password stays on the server. The panel is protected by login, optional 2FA, rate limiting and HTTPS. If you expose it to the internet, use a real domain name and keep 2FA enabled for every account.
description=
